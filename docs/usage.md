# 会话标题使用说明

适配 DeepSeek Harness `0.2.2-rc.3`。安装方式见 [README](../README.md)。

## 第一次使用

打开一个工作区会话，发一条有明确主题的任务，例如「设计日历邀请的提醒文案」。插件默认提示助手在回复结束前按该工作区模板整理标题。日期取会话创建时间，按北京时间换算。当前版本依赖助手调用整理工具。有时助手会跳过、遇到标题冲突，或在下一轮再判断。打开 **设置 → 插件 → 会话标题** 可以查看自动整理是否开启。

只想改一条标题时，用 DSH 会话菜单里的「重命名」。批量整理会保留宿主已标记为用户设置的标题，其中也可能包括旧版插件已整理的标题。

## 批量整理

1. 在会话顶栏点 **批量整理 → 整理会话**。
2. 确认范围。默认选当前工作区；也可选其他或全部工作区。全部工作区会各自使用自己的模板。已归档、未分组、正在运行和空会话等会被排除。
3. 点 **一键整理**。需要重新拟题时，插件用 DSH 默认模型读取少量用户消息片段来判断主题和类型。
4. 查看已整理、跳过和未完成的结果。可以停止处理后续会话，或者在本次面板里撤销标题尚未再次变动的改名。关闭面板或开始新一批前，请先处理本次需撤销的记录。

界面显示的「可检查」数量是范围内候选数，其中可能有格式已符合、标题固定等会跳过的会话。读回成功才算改名成功。

## 新建并引用模板

1. 打开 **批量整理 → 模板库**。内置 **Skill 默认** 包含功能、设计、修复、优化、发布、探索、文档、研究。
2. 选一个模板，点 **新建模板**。它会复制所选模板的格式和类型。填写名称后，可逐项增删类型、改名或加用途说明。通过实时示例检查输出。
3. 保存后切到 **整理会话**，选择工作区。在 **工作区使用的模板** 里选新模板，然后点 **应用到工作区**。
4. 给其他工作区应用同一模板即可复用。编辑模板时会显示引用它的工作区数量。删除模板前，需要把仍在引用它的工作区切换到其他模板。

旧版按工作区保存的格式和类型会在模板库显示为已引用的命名模板。第一次保存新配置时，插件会将这些引用写入新版存储。

### 格式示例

| 模板 | 示例 |
| --- | --- |
| `{日期}｜{类型}｜{主题}` | `1116｜设计｜日历邀请提醒` |
| `{主题}` | `日历邀请提醒` |
| `【{工作区}】{主题}` | `【北辰研发】日历邀请提醒` |
| `{日期:YYYY年M月D日} / {主题}` | `2026年11月16日 / 日历邀请提醒` |

可用 `{日期}`、`{工作区}`、`{类型}`、`{主题}`，也可以自由省略、重复和搭配单行文字。自定义日期支持 `YYYY`、`YY`、`MM`、`DD`、`M`、`D`。最终标题受 DSH 的 80 个 UTF-8 字节限制。

## 外观、自动整理开关与排查

- 在 **设置 → 插件 → 会话标题** 可以设置顶栏文字或图标、模板编辑排版和预览样式；外观保存在本机客户端。
- 需要暂停自动整理时，给目标 profile 的 `cordis.patch.yml` 添加或编辑以下配置，重新加载 profile：

  ```yaml
  - id: conversation-title
    config:
      automatic: false
  ```

- 如需替换内置规则，可配置 `skillPath`，指向可读的本地 conversation-title Skill 绝对路径。默认包内规则开箱可用。配置的文件不可读时，依赖规则的整理会暂停，插件页会显示状态。
- 顶栏没有入口时，检查插件安装到了正在使用的 profile、处于启用状态，并重新打开 DSH。如果一次批量操作结果待确认，先核对宿主标题再重试。
